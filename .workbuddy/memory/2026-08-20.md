## 部署 gaoxiaoweb（高校官网 POC）到远程服务器

**目标服务器**：186.241.89.117（Ubuntu 22.04, 2 vCPU, 2GB RAM + 2GB swap, root SSH 密码登录）
**访问地址**：http://186.241.89.117/ （已公网可访问，HTTP/80）

### 服务器结构
- 代码：`/opt/campus-site/{cms,frontend}`
- 密钥/环境变量：`/etc/campus-site/{cms.env, frontend.env}`（权限 640）
- CMS 只读 Token：`/etc/campus-site/cms.token`（权限 600，full-access，仅服务端用）
- systemd：`campus-cms.service`（Strapi, 127.0.0.1:1337）、`campus-frontend.service`（Next, 127.0.0.1:3000）
- Nginx：`/etc/nginx/sites-available/campus-web.conf`（反代 127.0.0.1:3000，:80）

### 关键踩坑（重要）
1. **2GB 内存 OOM**：Strapi `build` 与 `next build` 需 `NODE_OPTIONS=--max-old-space-size=1500`；npm 命令用后台 `nohup ... >log 2>&1 &` + 轮询，避免超时强杀。
2. **npm ci 漏装 devDependencies**：因 source 了含 `NODE_ENV=production` 的 env 导致。重装须 `npm ci --include=dev`（Tailwind v4 的 `@tailwindcss/postcss` 是 devDep，缺它会 build 失败 `Cannot find module '@tailwindcss/postcss'`）。
3. **Strapi 单类型 site-setting 无条目时返回 404**（集合类型无数据返回 200）。前台 `lib/cms.ts` 对非 2xx 会抛错并重试→构建失败。修复：用 full-access Token 经 PUT 创建一条 site-setting 记录，GET 才返回 200。
4. **read-only Token 不含单类型权限**：site-setting 用只读 Token 仍 404，故前台改用 full-access Token（仅服务端，不进浏览器，POC 可接受）。
5. Strapi 首次启动需先建 `public/uploads` 目录，否则启动崩溃。
6. 前台需先 `strapi admin:create-user` 建管理员，再经 Admin API 建 API Token。
